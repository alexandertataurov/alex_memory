# Find in Notion

Turn the supplied query into a concrete entity-focused search. Prefer names
and distinctive terms (for example, `Alex Memory contact profile evidence`) to
category words. Return compact result titles/statuses, then retrieve a page
only when it is needed for the task. Do not enumerate the workspace or fetch
all search results. State when no reliable match is found.
