# Compare status

Search for the specific project or task first, then retrieve the smallest
relevant status/task/decision pages. Compare their state with `TASKS.md`,
active ExecPlans, current docs, and code. Report only substantiated
discrepancies: stale Notion status, missing implementation evidence, completed
work not reflected in Notion, conflicting requirements, or duplicated tasks.
Do not modify either side without the user's authorization for that change.
